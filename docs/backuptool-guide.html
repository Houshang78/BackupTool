backuptool — User Guide

Cross-platform, parallel, incremental backup tool with a native GUI, selectable encryption, and per-system backup sets. Two independent implementations: Python (Qt6) and Rust (Slint).

1. Two implementations

Pick whichever you prefer — both share the same manifest format and concepts.

VariantGUIBuild / run
PythonQt6 (PySide6)./backuptool-portable or pip install .
RustSlint (native)cargo build --release

2. Install

Linux

# Python:  bash packaging/build-deb.sh && sudo apt install ./dist/backuptool_1.0.0_all.deb
# Rust:    cargo build --release   (GUI: cargo build --release --features gui)

macOS

# Python:  bash packaging/build-macos.sh   (backuptool.app + .pkg)
# Rust:    cargo build --release --features gui --bin backuptool-gui

Windows

# Python:  powershell -File packaging\build-windows.ps1  ->  dist\backuptool.exe
# Rust:    cargo build --release --features gui
The Python GUI needs pip install PySide6. The CLI runs without it. The Rust binary is self-contained.

3. Graphical interface

The window has a language selector (English / Deutsch / فارسی; drop a lang/<code>.json file to add more). Choose sources, the destination / backup drive, the set name, worker count, the checksum compare, and the encryption from a dropdown. Progress and a log are shown live.

4. Command line

backuptool backup ~/ -d /Volumes/Backup -s my-laptop --progress
backuptool backup ~/ -d /Volumes/Backup -c -j 8        # BLAKE3/SHA compare, 8 workers
backuptool backup ~/ -d /Volumes/Backup --cipher aes256gcm
backuptool list    -d /Volumes/Backup
backuptool restore -S /Volumes/Backup -s my-laptop -t /

5. Incremental compare

Each set has a manifest. By default a file is “changed” when size or mtime differ; with -c when the checksum (SHA-256 / BLAKE3) differs. Only changed files are copied.

6. Backup sets (multiple systems)

With -s NAME each machine gets its own subfolder + manifest in the same destination, so you can back up several systems to one drive.

7. Encryption

Selectable: none, AES-256-GCM, or ChaCha20-Poly1305. The key is derived from a password with Argon2id (random salt per set). File contents are stored as ciphertext; the manifest stays readable (paths/metadata only).

8. exFAT & permissions

exFAT cannot store Unix permissions, yet metadata (mode, owner, mtime) live in the manifest and are reapplied on restore. So an exFAT drive works everywhere (Linux/macOS/Windows) without losing rights.

9. Restore

backuptool restore -S /Volumes/Backup -s my-laptop -t /tmp/test -n   # dry run first
sudo backuptool restore -S /Volumes/Backup -s my-laptop -t /         # uid/gid needs root
Target / modifies the running system — always dry-run (-n) first.

backuptool — Bedienungsanleitung

Plattformübergreifendes, paralleles, inkrementelles Backup-Tool mit nativer GUI, wählbarer Verschlüsselung und Backup-Sets je System. Zwei unabhängige Umsetzungen: Python (Qt6) und Rust (Slint).

1. Zwei Umsetzungen

Nimm, was dir lieber ist — beide teilen Manifest-Format und Konzepte.

VarianteGUIBauen / Starten
PythonQt6 (PySide6)./backuptool-portable oder pip install .
RustSlint (nativ)cargo build --release

2. Installation

Linux

# Python:  bash packaging/build-deb.sh && sudo apt install ./dist/backuptool_1.0.0_all.deb
# Rust:    cargo build --release   (GUI: cargo build --release --features gui)

macOS

# Python:  bash packaging/build-macos.sh   (backuptool.app + .pkg)
# Rust:    cargo build --release --features gui --bin backuptool-gui

Windows

# Python:  powershell -File packaging\build-windows.ps1  ->  dist\backuptool.exe
# Rust:    cargo build --release --features gui
Die Python-GUI braucht pip install PySide6. Die Kommandozeile läuft ohne. Die Rust-Binary ist eigenständig.

3. Grafische Oberfläche

Das Fenster hat eine Sprachauswahl (English / Deutsch / فارسی; weitere Sprache per lang/<code>.json ergänzbar). Wähle Quellen, Ziel/Sicherungsplatte, Set-Namen, Worker-Zahl, den Prüfsummen-Abgleich und die Verschlüsselung per Dropdown. Fortschritt und Log laufen live.

4. Kommandozeile

backuptool backup ~/ -d /Volumes/Backup -s mein-laptop --progress
backuptool backup ~/ -d /Volumes/Backup -c -j 8        # Prüfsummen-Abgleich, 8 Worker
backuptool backup ~/ -d /Volumes/Backup --cipher aes256gcm
backuptool list    -d /Volumes/Backup
backuptool restore -S /Volumes/Backup -s mein-laptop -t /

5. Inkrementeller Abgleich

Jedes Set hat ein Manifest. Standardmäßig gilt eine Datei als „geändert", wenn Größe oder mtime abweichen; mit -c, wenn die Prüfsumme (SHA-256 / BLAKE3) abweicht. Nur Geändertes wird kopiert.

6. Backup-Sets (mehrere Systeme)

Mit -s NAME bekommt jedes System einen eigenen Unterordner + Manifest im selben Ziel — so sicherst du mehrere Rechner auf eine Platte.

7. Verschlüsselung

Wählbar: none, AES-256-GCM oder ChaCha20-Poly1305. Der Schlüssel wird per Argon2id aus dem Passwort abgeleitet (zufälliges Salt je Set). Dateiinhalte liegen als Chiffrat vor; das Manifest bleibt lesbar (nur Pfade/Metadaten).

8. exFAT & Rechte

exFAT speichert keine Unix-Rechte, doch die Metadaten (Modus, Eigentümer, mtime) stehen im Manifest und werden beim Restore wieder gesetzt. So funktioniert eine exFAT-Platte überall (Linux/macOS/Windows), ohne Rechte zu verlieren.

9. Wiederherstellen

backuptool restore -S /Volumes/Backup -s mein-laptop -t /tmp/test -n   # erst Probelauf
sudo backuptool restore -S /Volumes/Backup -s mein-laptop -t /         # uid/gid nur als root
Ziel / verändert das laufende System — immer zuerst Probelauf (-n).

backuptool — راهنمای کاربری

ابزار پشتیبان‌گیری چندسکویی، موازی و افزایشی با رابط گرافیکی بومی، رمزنگاری قابل‌انتخاب و مجموعه‌های پشتیبان مجزا برای هر سیستم. دو پیاده‌سازی مستقل: پایتون (Qt6) و راست (Slint).

۱. دو پیاده‌سازی

هرکدام را که می‌پسندید انتخاب کنید — هر دو قالب مانیفست و مفاهیم یکسانی دارند.

نسخهرابط گرافیکیساخت / اجرا
پایتونQt6 (PySide6)./backuptool-portable یا pip install .
راستSlint (بومی)cargo build --release

۲. نصب

لینوکس

# پایتون:  bash packaging/build-deb.sh && sudo apt install ./dist/backuptool_1.0.0_all.deb
# راست:    cargo build --release   (رابط گرافیکی: cargo build --release --features gui)

مک

# پایتون:  bash packaging/build-macos.sh   (backuptool.app + .pkg)
# راست:    cargo build --release --features gui --bin backuptool-gui

ویندوز

# پایتون:  powershell -File packaging\build-windows.ps1  ->  dist\backuptool.exe
# راست:    cargo build --release --features gui
رابط گرافیکی پایتون به pip install PySide6 نیاز دارد. خط فرمان بدون آن کار می‌کند. باینری راست مستقل است.

۳. رابط گرافیکی

پنجره یک انتخاب‌گر زبان دارد (English / Deutsch / فارسی؛ برای افزودن زبان، فایل lang/<code>.json را قرار دهید). منابع، مقصد/دیسک پشتیبان، نام مجموعه، تعداد کارگرها، مقایسهٔ چک‌سام و رمزنگاری را از فهرست کشویی انتخاب کنید. پیشرفت و گزارش به‌صورت زنده نمایش داده می‌شوند.

۴. خط فرمان

backuptool backup ~/ -d /Volumes/Backup -s my-laptop --progress
backuptool backup ~/ -d /Volumes/Backup -c -j 8        # مقایسهٔ چک‌سام، ۸ کارگر
backuptool backup ~/ -d /Volumes/Backup --cipher aes256gcm
backuptool list    -d /Volumes/Backup
backuptool restore -S /Volumes/Backup -s my-laptop -t /

۵. مقایسهٔ افزایشی

هر مجموعه یک مانیفست دارد. به‌طور پیش‌فرض یک فایل وقتی «تغییر‌یافته» است که اندازه یا زمان تغییر فرق کند؛ با -c وقتی چک‌سام (SHA-256 / BLAKE3) فرق کند. فقط موارد تغییر‌یافته کپی می‌شوند.

۶. مجموعه‌های پشتیبان (چند سیستم)

با -s NAME هر دستگاه پوشه و مانیفست مخصوص خود را در همان مقصد می‌گیرد — پس می‌توانید چند سیستم را روی یک دیسک پشتیبان بگیرید.

۷. رمزنگاری

قابل‌انتخاب: none، AES-256-GCM یا ChaCha20-Poly1305. کلید با Argon2id از گذرواژه ساخته می‌شود (نمک تصادفی برای هر مجموعه). محتوای فایل‌ها به‌صورت رمزشده ذخیره می‌شود؛ مانیفست خوانا می‌ماند (فقط مسیرها/فراداده).

۸. exFAT و مجوزها

exFAT نمی‌تواند مجوزهای یونیکس را ذخیره کند، اما فراداده (حالت، مالک، زمان) در مانیفست است و هنگام بازگردانی دوباره اعمال می‌شود. بنابراین یک دیسک exFAT همه‌جا (لینوکس/مک/ویندوز) بدون از دست رفتن مجوزها کار می‌کند.

۹. بازگردانی

backuptool restore -S /Volumes/Backup -s my-laptop -t /tmp/test -n   # ابتدا اجرای آزمایشی
sudo backuptool restore -S /Volumes/Backup -s my-laptop -t /         # uid/gid نیازمند root
مقصد / سیستم در حال اجرا را تغییر می‌دهد — همیشه ابتدا اجرای آزمایشی (-n).
